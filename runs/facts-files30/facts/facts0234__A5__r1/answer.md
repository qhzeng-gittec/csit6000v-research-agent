<answer>
According to doc.txt, the security functions in firewalls have enlarged alongside the changing network landscape [E1], and the enhanced capabilities provide the following benefits to network security:

- **Packet filtering and NAT** monitor and control packets moving across a network interface, apply predetermined security rules, and obscure the internal network from the public internet [E2].
- **Stateful inspection** monitors the state of connections and determines which data packets belong to a known active connection and can be allowed through [E3].
- **Deep packet inspection (DPI)** examines both the header and payload of packets, enabling the firewall to find hidden threats within the data stream, such as attempts at data exfiltration, violations of content policies, and malware [E4].
- **Threat detection and response** lets modern firewalls gather and analyze data across multiple packets and sessions to detect threats and security incidents targeted at a particular system or family of systems; this data can be sent to a SIEM and correlated with other security tools to detect enterprise-wide attacks spanning multiple systems and network layers, and can be used to understand evolving threats and define new access rules, attack patterns, and defensive strategies [E5].
- **Logging and auditing** construct network events that help identify patterns of performance and security issues [E6].
- **Access control functions** enforce granular, sophisticated access control policies [E7].
- **Deployment at multiple locations** provides layered protection: edge firewalls protect the network perimeter by filtering disallowed sources and destinations and blocking packets of potential threats; data-center firewalls segment the internal network to prevent lateral movement of traffic and isolate sensitive resources; and device-based firewalls prevent malicious traffic in and out of endpoints [E8].
- **Open APIs** enable integration with many networking products that provide additional security capabilities [E9].
- **Policy composition** allows firewalls to merge policies at enforcement time so that consistent policies are applied to different classes of users, such as those on-premises and on private and public clouds [E10].
- **Web application firewalls (WAFs)** with advanced URL filtering detect traffic from malicious URLs and prevent web-based threats and attacks using real-time data analyzed by machine learning; they can inspect threat vectors such as SQL injection, OS command injections, and cross-site scripting attacks, prevent inbound attacks, and are used in CDNs and to prevent DDoS attacks [E11].
