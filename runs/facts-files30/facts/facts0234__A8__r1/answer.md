

Based on `doc.txt`, the "Enhanced Firewall Capabilities" section describes how firewall security functions have "enlarged alongside the changing network landscape," and the benefits of these enhanced capabilities to network security include:

- **Packet filtering and NAT**: used "to monitor and control packets moving across a network interface, apply predetermined security rules, and obscure the internal network from the public internet."
- **Stateful inspection**: "monitors the state of connections and makes determinations as to what types of data packets belong to a known active connection and can be allowed to pass through the firewall."
- **Deep packet inspection (DPI)**: examines "the content of packets (both the header and the payload)" and has "capabilities related to finding hidden threats within the data stream, such as attempts at data exfiltration, violations of content policies, malware, and more."
- **Threat detection and response**: modern firewalls "can gather and analyze enough data across multiple packets and sessions to detect threats and security incidents targeted at a particular system or a family of systems"; data from multiple firewalls can be correlated via SIEM "to detect enterprise-wide attacks that span multiple systems and network layers," and "used to understand evolving threats and define new access rules, attack patterns, and defensive strategies."
- **Logging and auditing**: "result in the construction of network events that can be used to identify patterns of performance and security issues."
- **Access control functions**: "enforce granular sophisticated access control policies."
- **Multiple locations and functions**: edge firewalls provide "network perimeter protection function by filtering disallowed sources and destinations and blocking the packets of potential threats"; data-center firewalls "can segment the internal network to prevent the lateral movement of traffic and isolate sensitive resources (e.g., services and data stores)"; device-based firewalls "prevent malicious traffic in and out of endpoints."
- **Open APIs**: "enable integration with many networking products that provide additional security capabilities."
- **Policy composition**: "merge policies at enforcement time so as to ensure that consistent policies are applied to different classes of users (e.g., those on-premises and on private and public clouds)."
- **Web application firewalls (WAF)**: with advanced URL filtering, they can "detect traffic from malicious URLs and prevent web-based threats and attacks," "inspect threat vectors for SQL Injection, operating system (OS) command injections, and cross-site scripting attacks, as well as prevent inbound attacks," and are "used in content delivery networks (CDN) and to prevent distributed denial-of-service (DDoS) attacks."
- **Next-generation firewalls (NGFW)**: provide "application data awareness," looking at data "not only at layers 3 and 4 of an Open Systems Interconnection (OSI) stack but also at layer 7 – the application level," with capabilities including "Deep Packet Inspection (DPI)," "TLS decryption and inspection of packet payload," and an "Intrusion prevention system (IPS) feature."
- **Web application and API protection (WAAP)**: described as "a comprehensive security approach and an enhancement over WAF," integral "for API security, BOT (abbreviation for Robot) defense, and DDOS protection."
- **Secure web gateways (SWGs)**: "protects outbound user traffic through HTTP or Hypertext Transfer Protocol Secure (HTTPS) inspection" and "protects user endpoints from web-based threats that can occur when users click on links to malicious websites or to websites infected with malware."
