<answer>
According to doc.txt, firewall security functions have enlarged alongside the changing network landscape [E1], and the enhanced capabilities provide several benefits to network security:

- **Basic protection and concealment:** Packet filtering and NAT monitor and control packets across a network interface, apply predetermined security rules, and obscure the internal network from the public internet [E2].
- **Deeper threat detection:** Deep packet inspection examines both packet headers and payloads, enabling the firewall to find hidden threats within the data stream, such as attempts at data exfiltration, violations of content policies, and malware [E3].
- **Threat detection and response:** Modern firewalls gather and analyze data across multiple packets and sessions to detect threats and security incidents targeted at a particular system or family of systems [E4]. Data from multiple firewalls can be sent to a SIEM and correlated with other security tools to detect enterprise-wide attacks spanning multiple systems and network layers [E5], and the data can also be used to understand evolving threats and define new access rules, attack patterns, and defensive strategies [E6].
- **Internal segmentation:** Firewalls inside a data center can segment the internal network to prevent lateral movement of traffic and isolate sensitive resources such as services and data stores [E7].
- **Web application protection:** Web application firewalls with advanced URL filtering can detect traffic from malicious URLs and prevent web-based threats and attacks using real-time data analyzed by machine learning [E8]. They can inspect threat vectors for SQL injection, OS command injections, and cross-site scripting attacks, prevent inbound attacks [E9], and are used in content delivery networks and to prevent distributed denial-of-service (DDoS) attacks [E10].
