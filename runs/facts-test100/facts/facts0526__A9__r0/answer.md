

Based on `doc.txt`, the President's FY2024 budget request recommended a package of legislative changes to improve UI program integrity. The provisions that would create requirements for states are:

1. **Data matching** — The proposals would have codified the requirement for states to data match with the National Directory of New Hires (NDNH, administered by HHS) and the Prisoner Update Processing System (PUPS, administered by the Social Security Administration), to help ensure UI benefits are correctly paid to eligible individuals in a timely manner. (Footnote 54 notes that states are currently required to use NDNH only via DOL program guidance, and that there is no statutory requirement for states to use NDNH or several other related data cross matches.)

2. **Disclosure to DOL-OIG** — The proposals would have required states to disclose information to the DOL Office of the Inspector General (DOL-OIG) to streamline DOL-OIG's ability to conduct audits and investigations in the UI program. This includes authorizing DOL-OIG to have direct access to the Interstate Connection Network (ICON), used for electronic transmission of interstate claims, and the Integrity Data Hub (IDH) system, used in cross-matching UI claimants against other databases to prevent and detect fraud and improper payments.

3. **Use of penalty and interest collections** — The proposals would have required states to use penalty and interest collections solely for UI administration.

In addition, the package would have allowed the DOL Secretary to require a portion of a state's administrative grant to be used to correct failing performance and/or to have the state participate in required technical assistance activities offered by DOL — a conditional requirement the Secretary could impose.

The remaining provisions in the package (retaining up to 5% of recovered fraudulent overpayments, issuing formal warnings when claimants do not clearly meet work search requirements, and using contract support in Treasury Offset Program recovery efforts) are described in the document as authorizations or allowances for states rather than requirements.
