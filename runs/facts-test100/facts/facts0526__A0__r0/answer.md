

Based on `doc.txt` (a CRS report, "Unemployment Insurance: Legislative Issues in the 118th Congress"), the President's FY2024 budget request recommended a package of program-integrity legislative changes. The provisions that would create **new requirements for states** are:

1. **Data matching with federal databases** — The proposal would codify the requirement for states to data match with the National Directory of New Hires (NDNH, administered by HHS) and the Prisoner Update Processing System (PUPS, administered by SSA), to help ensure UI benefits are correctly paid to eligible individuals in a timely manner. The document notes this would be a new statutory obligation: "Currently, there is no statutory requirement for states to use NDNH or several other related data cross matches" (states currently use NDNH only via DOL program guidance).

2. **Disclosure of information to the DOL Office of Inspector General** — States would be required to disclose information to the DOL-OIG to streamline its audits and investigations in the UI program. This includes authorizing DOL-OIG to have direct access to the Interstate Connection Network (ICON), used for electronic transmission of interstate claims, and to the Integrity Data Hub (IDH) system, used to cross-match UI claimants against other databases to prevent and detect fraud and improper payments.

3. **Use of penalty and interest collections** — States would be required to use penalty and interest collections solely for UI administration.

In addition, the package would give the **DOL Secretary new authority to require** that a portion of a state's administrative grant be used to correct failing performance and/or that the state participate in required technical assistance activities offered by DOL — a conditional requirement that could be imposed on states.

The remaining provisions in the package are authorizations rather than requirements: they would allow states to retain up to 5% of recovered fraudulent UI overpayments for program integrity use, give states authority to issue a formal warning when claimants do not clearly meet work search requirements, and allow states to use contract support in recovery efforts under the Treasury Offset Program (TOP).
