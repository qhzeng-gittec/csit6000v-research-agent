

Based on `doc.txt`, here is the beep count for each requested setting (all performed in Learn Mode):

1. **Right-handed operation** – "One beep indicates the unit is set to standard 'right-handed' mode" → **1 beep**
2. **Cursor speed to 2** – "Each time you do so, the unit emits a number of beeps, between 1 and 4" → speed 2 = **2 beeps**
3. **Double click** – "two beeps indicates 'Double-Click' operation" → **2 beeps**
4. **Buzzer off** – "press and hold the right button while in Learn Mode, until two long beeps are heard" → **2 beeps** (the buzzer still operates while in Learn Mode, so these are heard)

**Total: 1 + 2 + 2 + 2 = 7 beeps.**

(Note: the warbling tones heard when entering and leaving Learn Mode are not beeps, so they are not counted.)
