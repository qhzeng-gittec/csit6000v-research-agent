Based on `doc.txt`, the difference is in how they are used:

- A method is a special function bundled with a string (a "string method"), written with a leading dot (e.g., `.lower()`), and "must be used in conjunction with a string. They do not exist independently." (doc.txt)
- A function like `len()` "is a stand-alone function" that you "call the len() function directly" (e.g., `len(name)`), without needing to be attached to a string. (doc.txt)

The document states: "Aside from the different results of these functions, the important distinction here is how they're used." (doc.txt)
